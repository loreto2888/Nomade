# Nómade · prototipo navegable

Prototipo del catálogo de 31 pantallas para administración y control financiero de obras. Abrir `index.html` en un navegador moderno; no requiere instalación ni servidor.

Los indicadores y registros son ficticios. La navegación, búsqueda y filtros sirven para revisar el diseño; las acciones de negocio muestran su alcance pendiente y no modifican datos.

Usa el menú lateral o los enlaces «Continuar en» para recorrer pantallas relacionadas. En teléfonos, abre el menú con el botón superior. La ficha de obra corresponde únicamente a Local Parque Norte, un ejemplo; los enlaces no representan datos persistidos.

**No es un sistema productivo.** No implementa autenticación, permisos, persistencia, auditoría, concurrencia, cálculo financiero ni integraciones. Laudus, Rindegastos, los formatos bancarios y las reglas de aprobación requieren levantamiento y validación antes de desarrollar e implementar la plataforma. No ingresar información real ni usarla para decisiones financieras.
